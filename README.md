# Sylvain Gaillard

Personal research homepage: https://sylvaingaillard44.github.io/

Static HTML and CSS with no build dependencies.

## Publishing

In the repository Settings → Pages, select **Deploy from a branch**, then **main** and **/ (root)**, and save.

## Editing

- `index.html`: biography, affiliation, contact details, and profile links.
- `style.css`: layout, colours, and responsive styling.
- `assets/sylvain-gaillard.jpeg`: original portrait, framed using CSS without modifying the photo.

To preview locally, run `python3 -m http.server 8000` from this directory and open http://localhost:8000.
